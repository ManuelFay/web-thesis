\chapter{Perspectives on Search}

Vannevar Bush had the vision that \emph{associative} knowledge would be the key insight unlocking retrieval capabilities \cite{bush1945aswemaythink}. Time proved him right, well aided by the advent of computing. Statistical retrieval engines transcend fixed classification systems linking queries to documents through their words, not just their general theme. Deep neural networks further broaden associative links by enabling matching across vastly different syntax, by exploiting semantical proximity which is encoded in a learned latent space. The contributions of this thesis could be seen as further efforts to improve \emph{search} by exploring the extent to which we can strenghen associative links.

At a high level, in \emph{Visual Document Retrieval} \sidecite{faysse2025colpaliefficientdocumentretrieval, loison2026vidorev3comprehensiveevaluation, teiletche2025modernvbert}, we demonstrate that cross-modal associations exist and can be leveraged for efficiently matching image parts to words. In our work on contextual embeddings \sidecite{conti2025context}, we show existing links between corpus documents can and should be exploited to facilitate retrieval. With CroissantLLM \sidecite{faysse_croissantllm_2024, meeus2024copyright}, we explore parametric memory consolidation through LLM training, and study which type of knowledge can be surfaced (searched) from the LLM memory through prompting (associative recall). This broader view of the \emph{search} landscape may help in uncovering future impactful research directions.



\section{Visualizing the memory hierarchy}

Viewing search solely through the lens of document retrieval is restrictive; a broader perspective is to understand search as memory access across a hierarchy of storage mediums. Humans answer questions by relying on internal memory, attending to information currently in view, consulting notes, or searching a library. These memory systems differ in capacity, latency, reliability, update cost, and provenance. LLM systems exhibit an analogous hierarchy. Model weights act as compressed parametric memory; the current context, together with the key-value cache, provides a transient working memory; and document stores, databases, tools, or the web provide external non-parametric memory.

This analogy is strengthened by recent work interpreting Transformers themselves through the lens of associative memory. In particular, \sidecite{zhong2025understandingtransformerperspectiveassociative} argue that both attention and feed-forward networks can be understood as memory systems, but with distinct retrieval and update properties. Attention constructs a dynamic associative memory over the current sequence, whereas feed-forward layers behave more like static learned associative stores. This suggests that failures in LLM search should not be viewed only as missing information, but more generally as failures of memory access: the information may be stored in the weights, present in the context, or available externally, yet still fail to be retrieved with sufficient salience.

Under this view, retrieval-augmented generation is only one memory operation: the promotion of information from external memory into working memory. Prompting elicits information from parametric memory; attention performs associative retrieval within the current context; indexing writes information into external memory; and fine-tuning, distillation, or model editing consolidate information into the weights. The central systems problem is therefore not document retrieval alone, but memory management across heterogeneous memory tiers. Bridging these memory hierarchies is a powerful avenue for future improvement, for instance by treating document-embedding retrieval more like long-context in-context retrieval, or conversely by treating long-context attention as a form of retrieval over an external memory.

\section{Towards Omnimodal Embeddings}


We argue that \emph{omnimodal} search will become central as the set of exploitable sources of information widens with model capabilites (text, images, audio, video, code, structured data, 3D models).
Recent projects such as BrowseComp illustrate the growing impact of AI agents on real-world information seeking and highlight that robust access to complex information benefits from \emph{adaptive compute}. Crucially, these systems still benefit from strong ``first-layer'' retrieval primitives such as embedding-based search for efficient candidate selection.


We further note that not all information is equally accessible: some sources remain costly to reach, poorly indexed, private, ephemeral... Exploiting such information at scale will therefore remain challenging in the coming years. Looking forward, we anticipate a shift from explicit querying toward more \emph{implicit} information access, where systems proactively surface relevant knowledge continuously in response to context, goals, and ongoing activity.
